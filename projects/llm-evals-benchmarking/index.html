Large-Scale LLM Evals & Provider Benchmarking Engine

Automated continuous evaluation system tracking latency, throughput, token pricing, and accuracy across 50+ model endpoints

Problem & Challenges

Cloud LLM API performance varies wildly across regions, times of day, and upstream provider updates. Engineers frequently suffer from silent model updates, sudden latency degradation, or throughput throttling without actionable data.

Engineered Solution

Distributed benchmarking architecture powered by scheduled GitHub cron jobs and the Unify Python client, orchestrating multi-region probes through Orchestra backend endpoints and publishing real-time telemetry, TTFT/ITL plots, and cost benchmarks to the ModelHub webapp deployed on GCP Cloud Run.

Technical Architecture

The large-scale benchmarking engine operates as an automated, closed-loop telemetry pipeline: modelhub renders the public leaderboard on Cloud Run, orchestra drives dynamic measurement dispatch per endpoint and region, unify conducts nanosecond probe timers against upstream LLMs, and github cron jobs execute automated sweeps every few hours:

1. modelhubCloud Run Webapp

Public web application deployed as a containerized Next.js/React service on Google Cloud Run with Global CDN edge caching. Powers interactive leaderboard views, dynamic region filtering, token pricing calculators, and responsive TTFT/ITL distribution charts.

2. orchestraBackend Logic & Dispatch

FastAPI backend holding measurement dispatch logic. Exposes endpoints to trigger dynamic benchmarks on any specified endpoint × region tuple, applies variance filtering to eliminate cloud transit jitter, and aggregates historical percentiles in PostgreSQL and Redis.

3. unifyPython Client SDK

Python client library interfacing directly with Orchestra endpoints and upstream LLM providers. Drives probe batteries, measures nanosecond TTFT and inter-token intervals via raw streaming chunk timestamps, and packages standardized telemetry payloads.

4. github cron jobsPeriodic Sweeps

Automated GitHub Actions workflows scheduled to execute continuous benchmark sweeps every X hours across active model@provider pairs and 5 global regions (us-east-1, eu-west-1, etc.), publishing fresh public leaderboards without manual intervention.
