Real-Time Zero-Shot Speech-Driven Avatar Animation

Low-latency streaming neural pipeline animating arbitrary portrait images from synthesized conversational speech

Problem & Challenges

Existing avatar synthesis models require multi-minute video training or suffer from high inference latency (>1s) and eerie robotic jitter, making interactive real-time voice conversations unnatural.

Engineered Solution

A Python asyncio and WebRTC pipeline turns live speech into a zero-shot talking portrait. Deepgram transcribes audio, OpenAI generates a response, and ElevenLabs and Replicate produce synchronized voice and video; rolling frame interpolation smooths transitions between clips.

Technical Architecture

The real-time avatar engine coordinates an asynchronous, multi-service streaming pipeline built in Python with asyncio, WebRTC, and Pydantic models: user speech is captured over WebRTC and transcribed in real time via Deepgram STT, streamed into OpenAI LLM with sentence-boundary chunking, converted to audio with ElevenLabs TTS, and used alongside the baseline portrait image in Replicate video generation with rolling frame interpolation:

1. Deepgram (Streaming STT)~42ms Latency

Maintains a persistent streaming WebSocket connection over WebRTC. Ingests raw 16kHz PCM audio frames from the client microphone, returning sub-50ms partial speech-to-text transcripts with interim confidence scoring.

2. OpenAI LLM (Asyncio Orchestrator)~58ms TTFT

Asynchronous Python worker validating schemas with Pydantic. Ingests finalized user queries and streams LLM response tokens through a punctuation-boundary splitter to dispatch complete conversational sentences to TTS without waiting for the full response.

3. ElevenLabs (Streaming TTS)~36ms Chunk Latency

Synthesizes high-fidelity 48kHz voice audio from streamed sentence chunks. Streams raw audio buffers alongside synchronized phoneme/viseme timing metadata required to drive facial landmark motion in the subsequent video generation stage.

4. Replicate Video Gen & Rolling InterpolatorZero Seam Jitter

Zero-shot neural video generation using the static profile image as baseline driven by the synthesized audio chunks. Employs a rolling first-and-last frame buffer to interpolate boundary frames between successive clips, ensuring smooth video playback without seam cuts over WebRTC.
