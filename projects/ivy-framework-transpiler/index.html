Problem & Challenges

Engineered Solution

Technical Architecture

Ivy unifies deep learning frameworks via a 3-stage AST compilation pipeline. The graph compiler extracts a static computational DAG from arbitrary dynamic source code, swaps framework-specific operations with unified frontend wrappers, normalizes arguments, and retraces into the target framework's backend execution graph:

1. Static & Dynamic AST Graph Tracing

Extracts symbolic Directed Acyclic Graphs (DAGs) directly from native code execution, capturing tensor node flows and argument parameters without evaluating eager runtime kernels.

2. Frontend Function Replacement

Replaces native source functions (e.g. jnp.matmul) with 1:1 Ivy frontend wrappers (ivy.frontends.jax.numpy.matmul) preserving native kwargs and positional signatures.

3. Zero-Copy Tensor Conversion

Transforms native framework arrays (jnp.array) to target tensor types (torch.tensor) via zero-copy buffer handoffs and memory wrapping wherever possible.

4. Target Backend Lowering & JIT

Retraces the normalized graph using target backend APIs (torch.matmul, torch.add), emitting native graphs ready for JIT compilation (XLA, Inductor, Grappler).
