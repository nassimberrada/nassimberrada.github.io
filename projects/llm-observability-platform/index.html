Universal LLM Observability & Dashboard Platform

High-throughput telemetry ingestion, real-time token streaming inspection, and customizable tiled analytics

Problem & Challenges

Debugging generative AI systems in production is notoriously difficult due to unstructured inputs, non-deterministic streaming tokens, complex nested tool calls, and high data ingestion volumes that overwhelm traditional APM tools.

Engineered Solution

Asynchronous telemetry pipeline built on PostgreSQL and Redis with a React/Next.js frontend. Features an interactive dashboard canvas supporting drag-and-drop tiles: token cost breakdowns, latency distribution heatmaps, semantic prompt clustering, and dynamic client-side generation diff visualizers.

Technical Architecture

The universal LLM observability platform is built across a high-performance decoupled architecture: console serves as the Next.js tiled workspace, orchestra processes and validates telemetry via FastAPI & PostgreSQL, unify instruments applications with non-blocking async hooks, and GCP/GCS manages scalable container deployments and immutable trace storage:

1. consoleFrontend Dashboard

Next.js & React frontend application providing a customizable tiled canvas to manage projects and dashboards. Features a dynamic client-side diff engine that aligns tokens and calculates side-by-side prompt and output deltas directly in the browser with zero backend round-trip latency.

2. orchestraLogging Backend & API

High-throughput FastAPI service exposing REST and WebSocket endpoints (/logs, /traces, /projects). Ingests arbitrarily complex JSON schemas, manages project state, and maintains structured metadata and raw trace indexes in PostgreSQL.

3. unifyPython Client SDK

Universal Python client library querying heterogeneous LLM endpoints (OpenAI, Anthropic, Bedrock, Gemini). Features the @unify.traced decorator to automatically capture nested call hierarchies, inputs, outputs, and token counts via background workers with zero critical-path latency.

4. GCP / GCSDeployment & Storage

Google Cloud deployment layer orchestrating containerized services across Cloud Run / GKE with Cloud Load Balancing. Leverages Google Cloud Storage (GCS) for immutable execution trace blobs, Parquet analytical partitions, and Cloud SQL for relational indexes.
