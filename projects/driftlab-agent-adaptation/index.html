DriftLab: Measuring Agent Adaptation in Non-Stationary Environments

A testbed and formal evaluation protocol measuring LLM agent adaptation dynamics across non-stationary workplace environments

Question

Static benchmarks evaluate language model agents on frozen tasks where rules and ground truth remain fixed. Deployed agents work in turbulent environments where routing policies flip, schemas mutate, and adversaries adapt. How can we quantify how many task encounters an agent needs to detect a latent shift, recover competence, and retain new rules without corrupting existing knowledge?

Approach

DriftLab constructs six deterministic, seeded workplace simulations where an evaluator records an immutable ledger of hidden ground truth while the agent interacts through natural task exchanges and in-role feedback. Environmental drift is controlled across abrupt, gradual, cosmetic, endogenous, and adversarial shifts. Adaptation is measured in affected-task encounters rather than raw steps, and memory substrates are evaluated under identical paired seeds.

Methodology

DriftLab pairs six seeded workplace worlds with controlled change protocols and an evaluator-only record of ground truth. This lets each memory setup face the same tasks and feedback, while four change probes measure detection, recovery, retention, and over-updating across three memory layers:

  • Deterministic Workplace Worlds & Latent Truth Maps · 6 Seeded Worlds. Instantiated six realistic workplace simulations (routing intake, order form-filling, retail inventory, codebase migration, claims fraud screening, pooled audience campaigns). Environments are strictly seeded so two agents face byte-identical episodes, maintaining a hidden truth map f_t(κ_t) at every step while presenting signal-free realistic text to the agent.
  • Controlled Drift Taxonomy & Change Topologies · 20 Protocols. Decoupled what changes (owned by the world via inert hooks) from when it changes (owned by the protocol). Spans abrupt change-points, gradual drift with deterministic truth, cosmetic restyling (re-rendering without schema change), endogenous drift (triggered by agent behavior), and adversarial drift (where a co-adapting fraud ring shifts tactics against agent approvals).
  • Encounter-Based Latency & Epistemic Metrics · Encounter Calculus. Adaptation is counted in affected-task encounters k rather than steps, removing environmental sampling density from scoring. Formulated detection latency d(c), recovery latency ρ(c), stability σ(c), retention window accuracy R(c), stale-memory relapse rate S(c), collateral interference I(c), and the over-update rate U under misleading feedback.
  • Substrate Isolation & Pre-Registered Paired Testing · Paired Bootstrap. Swapped seven memory substrates (None, Transcript, Notes, Skills, Beliefs, World Model, Fast+Slow) behind fixed pinned models (GPT-5.6-Luna, DeepSeek-V4.1-Flash, Qwen3.8-27B). Evaluated pre-registered hypotheses via paired effects Δ = (1/|S|) Σ [m_B(s) - m_A(s)] with 95% bootstrap confidence intervals, automating scope-qualified verdicts.

Findings

Empirical benchmark characterization, paired statistical effects (95% CI), and registered hypothesis falsifications synthesized from published evaluation runs:

  • Cosmetic Over-Reaction is Domain-Dependent (-0.133 Acc Drop on Form). Cosmetic changes cut form-filling accuracy by 0.133 (95% CI [-0.240, -0.025]) but had no effect on request routing. Formatting matters when it carries task meaning.
  • The World-Model Epistemic Paradox (U = 0.81 vs 0.30 Notes). With 15% misleading feedback, the world model over-updated at 0.81, versus 0.30 for notes. Explicit belief updates made memory more reactive to noise.
  • Adversarial Co-Adaptation vs Recovery Latency (+0.10 to +0.25 Acc Gap). Adversarial fraud screening reduced episode accuracy by 0.10 to 0.25 as tactics shifted 34 times, versus 20 in control. Frequent shifts mattered more than per-shift recovery time.
  • Universal Penalty of Delayed Credit Assignment (-0.25 to -0.42 Penalty). A six-step feedback delay reduced accuracy across models in both changing (-0.25 to -0.42) and stable worlds (-0.28 to -0.56). Delayed feedback hurt performance regardless of drift.
