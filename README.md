# Nassim Berrada — Personal Portfolio

A modern, high-craft personal website and portfolio built with Next.js 16 (App Router), TypeScript, and Tailwind CSS.

---

## 🚀 Quick Start

Ensure you have [Bun](https://bun.sh) (or Node.js 20+) installed:

```bash
# Install dependencies
bun install

# Start local development server
bun run dev

# Build optimized production bundle
bun run build

# Start production server
bun run start
```

Visit [http://localhost:3000](http://localhost:3000) to view the site.
